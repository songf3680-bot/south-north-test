# 测测你骨子里是南方还是北方人格

纯前端趣味人格测试，无需后端，双击 `index.html` 即可在手机/电脑浏览器运行。

## 文件
- `index.html` 页面结构（首页 / 答题 / 计算中 / 结果 / 分享图弹窗）
- `style.css` 国风视觉与响应式布局、切换动画
- `data.js` 40 道题、5 个性格维度、20 座城市人格文案
- `scoring.js` 评分引擎（归一化 → 与城市坐标求最近距离 → 南方浓度）
- `app.js` 交互逻辑与原生 Canvas 分享图生成
- `validate.js` 评分逻辑自检脚本：`node validate.js`

## 评分说明
五维：表达（直爽↔含蓄）、生活（豪放↔精致）、社交（热络↔边界）、情绪（外放↔内敛）、节奏（闲适↔拼搏）。
每个选项给 1~2 个维度加减分；累加后归一化到 [-1, 1]，与 20 座城市的目标坐标计算距离，最近者为匹配城市。
城市南北按秦岭—淮河线划分；“南方浓度”由前四维均值计算，所以会出现“南城北魂”“北城南心”等组合。

仅供娱乐，不是地理考试，也不是心理诊断。
